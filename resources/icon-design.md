## Generation prompt

Use case: logo-brand. Create one finished square desktop application icon for Peregrine, meaning a wanderer, NOT a falcon. Abstract exploration/journey symbol built from very few bold simple geometric shapes: an elegant winding trail bending upward toward a small distant circular destination, with an open horizon suggested by the negative space. Calm, distinctive, beautifully balanced, instantly legible at 16–32 pixels. Flat vector-like solid shapes, thick confident curves, restrained high-contrast colors, no texture, no gradients, no shadows, no fine details. Center the mark on a dark rounded-square icon tile with generous but not excessive inset; outside the rounded tile is transparent. The icon should fill most of the square canvas. No letters, no words, no birds, no feathers, no literal human, no compass rose, no mockup, no presentation sheet. Deliver only the single icon.
